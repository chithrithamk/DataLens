# DataLens — CSV Data Analyzer

DataLens is a beginner-friendly Python web application built using **Streamlit**. It offers an interactive and simple interface for users to upload any valid CSV file, explore tabular data, inspect comprehensive data quality metrics, visualize distributions, apply robust data cleaning transformations, and download cleaned datasets.

---

## ✅ Implemented Features

### 1. Robust CSV Ingestion & Parsing Error Diagnostics
- **Universal Format & Encoding Support**:
  - **Encodings**: Seamlessly handles UTF-8, UTF-8 with BOM (`\xef\xbb\xbf` generated by Microsoft Excel), UTF-16 (LE/BE BOM), Windows-1252 (`cp1252`), and Latin-1 (`iso-8859-1`).
  - **Newline Conventions**: Automatically handles Windows (`\r\n`), Unix (`\n`), and legacy Mac (`\r`) newlines without mangling rows.
  - **Quoting Standards**: Full support for RFC 4180 standard features, including embedded commas within quotes (`"Toronto, ON"`) and escaped double quotes (`"He said ""Hello"""`).
- **Informative Line-by-Line Diagnostics**:
  - When encountering malformed CSV lines with inconsistent column counts (e.g., `Expected 6 fields in line 22, saw 7`), DataLens performs structural parsing to pinpoint the exact problematic lines, expected field count, and actual field count.
  - Avoids silent failure: Never silently drops rows or truncates columns using `on_bad_lines="skip"`.
- **Safe CSV Recovery Mode**:
  - Available via an explicit user opt-in in the sidebar under **🛠️ Advanced Settings**.
  - Safely repairs minor trailing delimiter inconsistencies (such as extra empty trailing commas) without skipping or dropping rows.
  - Provides a transparent, auditable log detailing every affected line number, the repair action taken, and any omitted fields.

### 2. Universal Data Type Detection & Semantic Typing
- **Data-Driven Inference**: Automatically detects column types without hardcoded column names or dataset-specific logic:
  - **Numeric (Integer & Float)**: Automatically identifies numbers stored as native numeric or numeric strings (including thousand commas and whitespace).
  - **Boolean**: Recognizes booleans from `bool` dtypes and string representations (`true/false`, `yes/no`, `t/f`).
  - **Date/Time**: Reliably parses dates, timestamps, and ISO formats while avoiding misclassifying plain numbers or arbitrary codes.
  - **Categorical vs. Text**: Distinguishes low-cardinality categories from free-text descriptions.
  - **Mixed / Ambiguous**: Preserves mixed-type columns safely without data loss.
  - **All Missing**: Identifies columns with zero valid observations.
- **Enhanced Column Metadata**: Displays both the underlying pandas data type and the inferred semantic type.

### 3. Consistent Missing-Value Normalization
- **Universal Marker Recognition**: Standardizes empty cells, whitespace-only strings (`"   "`), and common null tokens (`NA`, `N/A`, `NULL`, `null`, `None`, `#N/A`, `nil`).
- **Contextual & Configurable Inference**: Inferred placeholder tokens (such as single dashes `"-"` or `"?"`) in columns that are otherwise numeric or date/time, without blindly stripping legitimate hyphens from text columns.
- **Sidebar Configuration**: In-app expander to configure or add custom missing-value markers.
- **Consistent Definition**: Used consistently across quality metrics, descriptive statistics, charts, and cleaning operations.

### 4. Data Quality Analysis
- **Comprehensive Quality Metrics**:
  - Total count of missing cells.
  - Total count of rows containing missing values (`rows_with_missing`).
  - Total count of columns containing missing values (`columns_with_missing`).
  - Total count of completely duplicate rows.
- **Missing Value Breakdown Table**: Reports exact missing-value counts and row-based percentages for each column.
- **Contextual Notifications**: Alerts users when data is clean, when missing markers were normalized, or when files contain zero data rows.
- **Division-by-Zero Safety**: Safe computation on empty and header-only datasets.

### 5. Descriptive & Non-Numeric Statistics
- **Eligible Numerical Statistics**: Computes count, mean, median, standard deviation, minimum, 25th, 50th, 75th percentiles, and maximum.
- **Exclusion of Booleans**: Boolean, categorical, and free-text columns are safely excluded from numeric statistics.
- **Robust Edge Case Handling**:
  - Handles infinite values (`inf`, `-inf`) by filtering them out before computing means and percentiles.
  - Handles constant columns (`std = 0.0`), single observations, and all-null columns without crashing.
  - Precision-preserving display with numbers formatted to two decimal places (`%.2f`).
- **Categorical & Temporal Summary**: Dedicated summary for non-numeric features displaying Count, Unique Values, Top / Mode Value, and Frequency.

### 6. Interactive Visualizations (Plotly Express)
- **Bar Chart**: Categorical groupings with optional numeric aggregations (**Sum**, **Average**, **Count**) or category frequency counts.
- **Histogram**: Continuous distribution modeling for eligible numeric columns with dynamic bin slider (5–100 bins).
- **Scatter Plot**: Bivariate numerical relationship visualization requiring at least two distinct numeric columns, with optional categorical coloring.
- **Safe Filtering**: Automatically drops missing values and infinities prior to rendering to avoid blank or crashing plots.

### 7. Robust Data Cleaning
- **Duplicate Row Removal**: Purges completely identical rows while retaining the first occurrence.
- **Flexible Missing Value Strategies**:
  - **Keep missing values**: Leaves dataset values as originally uploaded.
  - **Remove rows with missing values**: Drops rows containing at least one missing cell.
  - **Fill numeric with mean**: Computes column means for numeric columns (including string-encoded numbers) and safely casts to float if the mean is non-integer.
  - **Fill numeric with median**: Computes column medians for numeric columns.
  - **Fill with mode**: Imputes missing values with the most frequent value across numeric, categorical, boolean, and text columns with deterministic tie-breaking.
- **Non-Destructive Execution**: The original uploaded DataFrame is never mutated; all cleaning runs on normalized copies.
- **Detailed Audit Metrics**:
  - Initial and final dimensions (rows × columns).
  - Duplicate rows removed.
  - Rows dropped due to missing values.
  - Missing cells filled.
  - Missing cells remaining (with clear explanations for unsupported or all-missing columns).
  - Missing markers recognized.
  - List of columns modified during cleaning or normalization.
  - Truthful status banners (only reports "No changes necessary" if truly zero changes occurred).

### 8. Reliable CSV Export
- **Direct Download**: Instant export via Streamlit's `st.download_button`.
- **Index-Free Output**: Exported with `index=False` to prevent synthetic pandas index columns.
- **Clean Formatting**: Preserves valid text, numeric, boolean, and date/time data as standard UTF-8 CSV.
- **Session State Management**: Export data remains available across tab switching and is automatically reset when a new file is uploaded.

## 💻 Installation & Setup (Windows)

1. **Open PowerShell or Command Prompt** and navigate to the project directory:
   ```powershell
   cd DataLens
   ```

2. **Create a virtual environment**:
   ```powershell
   python -m venv .venv
   ```

3. **Activate the virtual environment**:
   ```powershell
   .venv\Scripts\Activate.ps1
   ```
   > *Note:* If PowerShell prompts an execution policy restriction, run:
   > ```powershell
   > Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
   > ```

4. **Install dependencies**:
   ```powershell
   pip install -r requirements.txt
   ```

---

## ▶️ Running the Application

With your virtual environment active, run:

```powershell
streamlit run app.py
```

The application will start on `http://localhost:8501`.

## ⚠️ Known Limitations & Supported Behavior

- **Character Encodings**: Supports UTF-8, UTF-8 with BOM, UTF-16 (LE/BE BOM), Windows-1252 (CP1252), and Latin-1 (ISO-8859-1). Specialized multi-byte encodings (e.g., Shift-JIS or EUC-KR) without a BOM should be converted to UTF-8 prior to upload.
- **Structural Inconsistencies**: When a CSV has rows with different numbers of fields, strict mode blocks ingestion and identifies the exact line numbers and field counts. Users can enable Safe CSV Recovery to automatically repair extra trailing delimiters without dropping rows.
- **Mixed-Type Columns**: To preserve data integrity and prevent data destruction, columns containing a mixture of valid numbers and non-missing text words (e.g. `["10", "20", "pending_review"]`) are preserved as `Mixed/Ambiguous` rather than forcefully coerced to numeric.
- **All-Missing Columns**: Columns containing 100% missing values cannot be imputed with mean or median and are preserved as missing rather than filled with arbitrary synthetic constants.
